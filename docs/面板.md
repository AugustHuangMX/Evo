# 页面（Evo 窗口里的面板）

改页面时读这份；改网页一律用 ui-ux-pro-max 这个 skill。

- 代码：`code/panel_app.py`（Flask），模板在 `panel/templates/`，样式、字体、脚本在 `panel/static/`
- 设计稿：`panel/prototype/Evo 界面设计.html`（双击用浏览器打开，会联网加载 React 和 Google 字体，只作参考；保持原样不改）。共 8 个画面：总览、战绩、设置、托盘与通知，各有黑夜和白天两版
- 两套主题用同一套页面 + CSS 颜色变量实现，支持"跟随系统"
- 正式面板不加载任何网上的内容；Evo 会联网的只有检查更新、一键更新、用户同意后的匿名统计（`telemetry.py`）和用户点了"显示"以后总览页的当前地图（`map_rotation.py`）
- 右上角"Evo 官方合作小程序：派圈助手"（2026-10-28 用户要求，0.4.3 起就显示，不等 0.5.0 的绑定微信）：每一页都有（先只放总览页，用户觉得突兀，当天改成每一页），在顶部那一行（主题按钮左边；`panel_app.template_globals`），描边的圆角按钮，前面是派圈助手的图标（用户给的，2048 像素原图裁掉空边缩成 64 像素，`paiquan-icon.png`），窗口窄时只留图标和"派圈助手"。点了弹出派圈助手的小程序码（电脑上没有能直接打开小程序的链接，用手机微信扫）：上面一行"Evo 官方合作小程序"、名字、白底的码（不写介绍，用户 10-28 定的）、"打开手机微信，点右上角的'+'→'扫一扫'"、关闭。码的图片 `panel/static/partner/paiquan.png`（用户 10-28 给的，从微信公众平台"小程序码及线下物料下载"下载）；没有这张图时按钮不显示（`panel_app.partner_qr`）。两张图属于派圈助手、不适用 AGPL，写在同一个文件夹的 `LICENSE.txt`

## 显示规则

- 段位和 RP 按游戏里的方式显示，如"钻石 I · 48 排位点数"：不显示分母、进度条和"距下一段还差"（每段要多少分不一样）
- 读不到的数据显示"—"
- 传奇名字前有小头像（战绩页自己和队友、总览页最近对局和传奇表现；2026-10-20 用户决定）：18 像素，单色、颜色跟随文字（原图是黑色的，深色主题下看不见），名字就在旁边，读屏软件跳过它；没有图标时（没认出、以后的新传奇）留出同样宽的空位，名字上下对齐。写法在 `panel/templates/_legend.html`，样式 `.legend-icon`
- 传奇头像的来源和许可：原图（Apex Legends Wiki 上的 SVG）放 `assets/legends/`，每个文件的许可不一样，写在那里的 `LICENSE.txt`（不适用 AGPL-3.0；新加的图标要先写进去）。`python tools/legend_icons.py` 按 `config/legends.json` 的英文名对上编号，去掉编辑信息、四周空白裁成一样多，生成 `panel/static/legends/<编号>.svg`，并把许可文件复制过去（随安装包发）。出了新传奇：放原图、写许可、运行一次

## 六维图（2026-10-28）

- 用户要求新增（原来说五维，用户同意加上"生存"变成六维）：总览页右边一列放小图（右上角"详细 →"到数据页），数据页"我的"最上面放大图（图 + 旁边的数字表：你 / 平均 / 前 5%）。范围跟着页面上的"近 30 局 / 全部"。代码 `code/radar.py`，模板 `panel/templates/_radar.html`
- 六项（顺时针，从正上方开始）：场均伤害、场均击杀、场均助攻、击杀参与率、英雄池、生存（前五率）
  - 击杀参与率 = (击杀 + 助攻) ÷ (击杀 + 助攻 + 老板分)：队友的击杀不是自己的助攻就是老板分，老板分越少越高（用户的说法）。实测和总结页的全队击杀对得上（差 3%）
  - 英雄池 = 局数占 5% 以上的传奇有几个（用户选的：偶尔玩一两局的不算，选"全部"时也不会越打越多）
- 和同分段的 Evo 玩家比（用户决定）：**外圈（满分）= 同分段前 5% 的玩家的水平**（每名玩家的场均排好序取第 95 百分位，超过也算满），**另一种颜色画同分段的平均**。用户先说"同分段这一项最强的那个玩家"，看了实际数字后改成前 5%：最强的往往只打了三四局、比第二名高一截，图会缩成中间一小块，来个新玩家就跳
  - 分段 = 最近一次读到的段位那一组（白金及以下 / 钻石 / 大师以上，和"全体玩家"的段位筛选一样）；那一组打了 3 局以上的玩家不到 20 名、读不到段位时和全部段位比；范围里没有排位局时和匹配的玩家比。卡片上写"和钻石的 98 名玩家比"
  - 数字来自全体玩家的汇总（服务器每名玩家的场均，见 `docs/底座.md`"匿名统计"），"你"在本机算：只算和比的玩家同一种模式的局，和服务器一样不算待确认的局（英雄池除外），击杀来自经验值页的局不算进场均击杀和击杀参与
- 样子：你 = 红色实线 + 圆点 + 淡红色填充，平均 = 蓝色虚线，外圈 = 前 5%（图下面有图例，不只靠颜色）；深色主题的红、蓝比 `--accent`、`--p3-bg` 暗一点（配色检查：深色底上亮度要在范围里），浅色主题直接用它们。每个顶点外面写项目名和自己的数字（HTML 字，图缩小了字不变小），悬停看平均和前 5%；小图的数字表只给读屏软件
- **只有开了匿名统计能看**（用户决定，和"全体玩家"一样）：没开时后面是几圈看不清的灰色六边形，上面一张小卡片（锁、一句话、"开启匿名统计"按钮、回到原来的页面）；不下载任何东西
- 开了：用存着的汇总；还没下载过时写"正在下载全体玩家的数据…"。没有、超过 24 小时（存着的是服务器加这几项以前的汇总时 1 小时）时，页面打开后在后台下载一次（`POST /stats/everyone/refresh`），好了只换掉这张卡片（`GET /radar`），不重新打开页面；没下载到写原因
- 读不到的项写"—"、不画那个顶点；读得到的不到 3 项不画自己的形状；平均要六项都有才画（汇总里缺几项时写"全体玩家的数据还不全"）。"全部账号"时不画，提示选一个账号
