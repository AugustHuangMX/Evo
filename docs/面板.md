# 页面（Evo 窗口里的面板）

改页面时读这份；改网页一律用 ui-ux-pro-max 这个 skill。

- 代码：`code/panel_app.py`（Flask），模板在 `panel/templates/`，样式、字体、脚本在 `panel/static/`
- 设计稿：`panel/prototype/Evo 界面设计.html`（双击用浏览器打开，会联网加载 React 和 Google 字体，只作参考；保持原样不改）。共 8 个画面：总览、战绩、设置、托盘与通知，各有黑夜和白天两版
- 两套主题用同一套页面 + CSS 颜色变量实现，支持"跟随系统"
- 正式面板不联网（例外是检查更新和一键更新，见项目原则 2）

## 显示规则

- 段位和 RP 按游戏里的方式显示，如"钻石 I · 48 排位点数"：不显示分母、进度条和"距下一段还差"（每段要多少分不一样）
- 读不到的数据显示"—"

## 总览页

- 段位卡片、RP 走势图：大厅读数比最后一局新时用大厅的（卡片上注明"大厅"），走势图在最后一局之后接上大厅读数
- 走势图：段位按 `config/ranks.json` 里每段的起点换算成连续分数（`ranks.py`；第 30 赛季：黄金 5500 起每段 750，钻石 12000 起每段 1000，大师 16000）；范围内的段位分界线画成虚线并标上段位名；下一段的分数线只在快升段时画，离得远就不画（免得折线被压扁）
- "今日"从早上 5 点算起：打到凌晨的局仍算前一天
- 读不到赛季，范围按钮只有"近 30 局 / 全部"，同时控制走势图、统计数字和传奇表现
- 传奇表现的横条按名次分段上色（冠军 / 第 2–3 / 第 4–10 / 其余），对应设计稿底部的图例
- 场均击杀不算击杀来自经验值页的局（那种局的击杀是计分次数）
- 顶部的"监测中"状态先不做：面板还不知道记录有没有在跑

## 战绩页

- 表格：名次、时间、模式、地图、传奇、击杀/助攻/击倒、伤害、生存时间、RP；急救、重生放在展开的详情里
- 点开一局：先只展开两名队友（两行，列和表头对齐，左边连接线连到名次徽章；名字旁写急救、重生，悬停显示 ID；传奇是对局中认出的）；识别截图和修改表单要再点"详情与修改"（网址加 `detail=1`），待确认的局直接全部展开
- 详情里有老板分、RP 从哪来（经验值页 / 对局中右上角 / 大厅校准）；修改表单能改名次、击杀、助攻、击倒、老板分、伤害、RP（还不能改传奇，见 todo.md）
- 确认或删除一局时，删掉这一局的截图

## 设置页

- 只放真正能用的选项；英文界面、开机自启、每局通知、性能模式、截屏测试、当前占用等以后的功能先不显示
- 现有：主题（跟随系统 / 黑夜 / 白天，跟随系统时 Windows 切换深浅色立即同步）；分辨率和界面语言（只读信息）；数据文件夹、截图文件夹（显示占用空间，能打开）；导出全部 CSV；清空所有战绩（清空前自动备份数据库，不删截图）；账号；更新（自动检查开关、检查更新、一键更新，见下面"更新"）；关于（版本、原则、源代码链接、"意见反馈"按钮：用系统浏览器打开 QQ 群加群链接，下面写群号）
- 截图（`screenshots.py`）：默认识别完就删，只留待确认的局要用的、确认后删；"保留全部截图"开关（默认关，开发者临时打开攒测试集；改了从下一局开始生效）；用源码运行时永远保留全部；以前存下的截图不自动删，用"删除已识别完的截图"按钮手动删

## 更新

- 第一次打开时页面顶部问一次要不要自动检查；有新版本时顶部出现蓝色提示条，设置页"更新"一栏显示更新内容
- 一键更新（`updater.py`，控件在 `panel/templates/_update.html`，提示条和设置页共用）："立即更新"→ 进度条（百分比、MB，可以取消；页面每半秒问一次 `/update/progress`）→ 解压 →"已下载好"和"安装并重新启动"按钮（2026-10-19 用户决定：下载完让玩家自己点一下，有个操作的段落感）→"正在安装"，窗口关几秒，新版本打开后顶部说一次"已更新到 x.y.z"
- Apex 开着时"安装并重新启动"变灰，原因写在按钮旁边（不只放在悬停提示里）；下载失败写原因，给"重试"和"去官网下载"
- 不能在 Evo 里更新时（用源码运行、单独运行面板、latest.json 里没有安装包信息）和以前一样只给官网链接

## 多账号

- 只有 1 个账号时界面和单账号一样；2 个以上时右上角出现"账号"切换，总览、战绩、传奇筛选、待确认数都只算选中的账号
- 每次打开窗口默认看最近玩过的账号（在小号上打完、打开 Evo 就是小号）；切换后在这个窗口里一直有效
- "全部账号"时段位卡片和 RP 走势图不显示（几个账号混在一起没有意义），提示选一个账号；导出 CSV 总是导出全部（有 player_name 列）
- 认出新名字时在窗口里弹窗问"是不是同一个人"；选错了在设置页"账号"一栏改（把名字并到别的账号或拆成单独一个）

## 通知

- **不能做成自定义的置顶窗口盖在游戏画面上**（等于游戏内浮层，违反原则 1；独占全屏时还可能把游戏切到后台）。只能用 Windows 系统通知（外观由系统决定），或者只在没玩游戏时弹出自定义卡片
