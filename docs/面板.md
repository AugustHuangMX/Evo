# 页面（Evo 窗口里的面板）

改页面时读这份；改网页一律用 ui-ux-pro-max 这个 skill。

- 代码：`code/panel_app.py`（Flask），模板在 `panel/templates/`，样式、字体、脚本在 `panel/static/`
- 设计稿：`panel/prototype/Evo 界面设计.html`（双击用浏览器打开，会联网加载 React 和 Google 字体，只作参考；保持原样不改）。共 8 个画面：总览、战绩、设置、托盘与通知，各有黑夜和白天两版
- 两套主题用同一套页面 + CSS 颜色变量实现，支持"跟随系统"
- 正式面板不加载任何网上的内容；Evo 会联网的只有检查更新、一键更新和用户同意后的匿名统计（`telemetry.py`）

## 显示规则

- 段位和 RP 按游戏里的方式显示，如"钻石 I · 48 排位点数"：不显示分母、进度条和"距下一段还差"（每段要多少分不一样）
- 读不到的数据显示"—"
- 传奇名字前有小头像（战绩页自己和队友、总览页最近对局和传奇表现；2026-10-20 用户决定）：18 像素，单色、颜色跟随文字（原图是黑色的，深色主题下看不见），名字就在旁边，读屏软件跳过它；没有图标时（没认出、以后的新传奇）留出同样宽的空位，名字上下对齐。写法在 `panel/templates/_legend.html`，样式 `.legend-icon`
- 传奇头像的来源和许可：原图（Apex Legends Wiki 上的 SVG）放 `assets/legends/`，每个文件的许可不一样，写在那里的 `LICENSE.txt`（不适用 MIT；新加的图标要先写进去）。`python tools/legend_icons.py` 按 `config/legends.json` 的英文名对上编号，去掉编辑信息、四周空白裁成一样多，生成 `panel/static/legends/<编号>.svg`，并把许可文件复制过去（随安装包发）。出了新传奇：放原图、写许可、运行一次

## 总览页

- 段位卡片、RP 走势图：大厅读数比最后一局新时用大厅的（卡片上注明"大厅"），走势图在最后一局之后接上大厅读数
- 走势图：段位按 `config/ranks.json` 里每段的起点换算成连续分数（`ranks.py`；第 30 赛季：黄金 5500 起每段 750，钻石 12000 起每段 1000，大师 16000）；范围内的段位分界线画成虚线并标上段位名；下一段的分数线只在快升段时画，离得远就不画（免得折线被压扁）
- "今日"从早上 5 点算起：打到凌晨的局仍算前一天
- 读不到赛季，范围按钮只有"近 30 局 / 全部"，同时控制走势图、统计数字和传奇表现
- 传奇表现的横条按名次分段上色（冠军 / 第 2–3 / 第 4–10 / 其余），对应设计稿底部的图例
- 场均击杀不算击杀来自经验值页的局（那种局的击杀是计分次数）
- 顶部的"监测中"状态先不做：面板还不知道记录有没有在跑

## 战绩页

- 表格：名次、时间、模式、地图、传奇、击杀/助攻/击倒、伤害、生存时间、RP；急救、重生放在展开的详情里
- 点开一局：先只展开两名队友（两行，列和表头对齐，左边连接线连到名次徽章；名字旁写急救、重生，悬停显示 ID；传奇是对局中认出的）；识别截图和修改表单要再点"详情与修改"（网址加 `detail=1`），待确认的局直接全部展开
- 详情里有老板分、RP 从哪来（经验值页 / 对局中右上角 / 大厅校准）；修改表单能改名次、击杀、助攻、击倒、老板分、伤害、RP（还不能改传奇，见 todo.md）
- 确认或删除一局时，删掉这一局的截图

## 数据页（2026-10-22）

- 用户决定新增，放各种统计；导航在"战绩"和"设置"之间（网址 `/stats`，模板 `stats.html`，数字在 `panel_app.py` 的"数据页的统计"）。以后的"最常用武器"也放这里（见 todo.md）
- 范围按钮和总览页一样（近 30 局 / 全部，默认近 30 局），只看选中的账号
- 每张表第一行是"所有对局"（参照，字色淡一级），和某个队友、某个传奇的数字对着看
- 常一起玩的队友：一起打过 2 局以上才列（排位单排时只遇到一次的路人不列）；表下只写一句"*将鼠标停在队友名字上可以看到ID"（2026-10-22 用户定的：不写"名次、RP 都是你自己的"这类说明，也不写几人没列；没有可列的队友时不写）；列：一起打几局、冠军（次数和比例）、场均名次、场均 RP，名次和 RP 都是自己的。按 ID 认人，改了名也算同一个人；没有总结页的局（队友只有名字）按名字对上 ID。显示最近 5 局里用得最多的名字（改名几局后换成新名字，读错一个字也不影响），名字下面写"上次一起"，悬停显示 ID
- 传奇表现（详细版）：每个用过的传奇一行（不合并成"其他"），按局数排；名次分布的横条按这个传奇自己的局数算比例（总览页的横条长短是局数），颜色和图例同总览页，横条带文字说明（读屏、悬停）；列：局数、胜率、前五率、场均名次 / 击杀 / 伤害 / RP。没认出传奇的局写明几局。总览页的传奇表现保留
- 场均数字和总览页共用 `group_numbers`：读不到的项不算进去、一局都没有写"—"；场均击杀不算击杀来自经验值页的局；RP 只算排位局

## 设置页

- 只放真正能用的选项；英文界面、每局通知、性能模式、截屏测试、当前占用等以后的功能先不显示
- 现有：第一栏"常规"：主题（跟随系统 / 黑夜 / 白天，跟随系统时 Windows 切换深浅色立即同步）、开机自动启动（开关显示 Windows 里实际的状态；在任务管理器里关掉了、启动项指向另一个位置的 Evo 时写在开关下面；没开成时开关下面红字写"没有成功开启自启，请检查是否被杀毒软件拦截"（2026-10-21 用户定的说法）；用源码运行、在压缩包里直接打开时开关变灰，写明原因；见 `docs/底座.md`）；第二栏"提示音"（2026-10-21：开关，默认开；下面按一局里的先后列出三声（对局结束、总结页读完了、经验值页）和什么时候响，各有"试听"按钮：不管开关都响，用脚本提交不刷新页面，按钮写"播放中…"约 1.2 秒，放不出来写"放不出来"；规则见 `docs/对局全流程图.md` 第 8 步）；分辨率和界面语言（只读信息）；游戏画面比例（2026-10-20：自动检测 / 16:9 / 16:10 / 4:3，下拉框 + 保存，下面写出自动检测的结果；自动检测读 Apex 的视频设置文件，见 `game_aspect.py`；记录程序每 5 秒看一眼，改了几秒内生效）；数据文件夹、截图文件夹（显示占用空间，能打开）；"更改数据位置…"（平时收起，点开后选文件夹 →"下一步"检查 → 写出要搬到哪里、多大、那个盘还剩多少，或者不能搬的原因、那里已有的数据，再点"开始搬"/"改用那份数据"；搬的时候顶部显示进度、不让改别的设置，见 `docs/底座.md`）；导出全部 CSV；清空所有战绩（清空前自动备份数据库，不删截图）；账号；匿名统计（见下面"匿名统计"）；更新（自动检查开关、检查更新、一键更新，见下面"更新"）；关于（版本、原则、源代码链接、"意见反馈"按钮：用系统浏览器打开 QQ 群加群链接，下面写群号）
- 截图（`screenshots.py`）：默认识别完就删，只留待确认的局要用的、确认后删；"保留全部截图"开关（默认关，开发者临时打开攒测试集；改了从下一局开始生效）；用源码运行时永远保留全部；以前存下的截图不自动删，用"删除已识别完的截图"按钮手动删

## 更新

- 第一次打开时页面顶部问一次要不要自动检查（回答了以后再问一次要不要开机自动启动：一次只问一件事；默认关，2026-10-21 用户决定）；有新版本时顶部出现蓝色提示条，设置页"更新"一栏显示更新内容
- 一键更新（`updater.py`，控件在 `panel/templates/_update.html`，提示条和设置页共用）："立即更新"→ 进度条（百分比、MB，可以取消；页面每半秒问一次 `/update/progress`）→ 解压 →"已下载好"和"安装并重新启动"按钮（2026-10-19 用户决定：下载完让玩家自己点一下，有个操作的段落感）→"正在安装"，窗口关几秒，新版本打开后顶部说一次"已更新到 x.y.z"
- Apex 开着时"安装并重新启动"变灰，原因写在按钮旁边（不只放在悬停提示里）；下载失败写原因，给"重试"和"去官网下载"
- 不能在 Evo 里更新时（用源码运行、单独运行面板、latest.json 里没有安装包信息）和以前一样只给官网链接

## 匿名统计（2026-10-22，0.3.7 起）

- 第一次打开时页面顶部问一次"愿意发送匿名的对局数据，帮助改进 Evo 吗？"（在自动检查、开机自启之后：一次只问一件事；默认不发）。"同意"和"不了"两个按钮一样的样式，不引导用户点同意；说明里有链接到设置页看原样
- 设置页单独一栏"匿名统计"（在"数据与隐私"和"更新"之间，`id="stats"`）：开关；下面一行状态（从什么时候起、已发送几局、上次发送的时间或没发出去的原因；关着时写"已关闭：不发送任何数据"）；"查看会发送的内容"（平时收起，点开是一次发送的原样 JSON，以最近一局为例，等宽字体，框里滚动）；发过数据（有随机编号）才显示"关闭并删除已发送的数据"（红色按钮，先弹确认框，点了写"正在删除…"；连不上时顶部写"没删成"，什么都不改）
- 战绩页保存修正时记下改了哪几项（`matches.edited`，只记列名），匿名统计的"识别情况"用；规则见 `docs/底座.md`"匿名统计"

## 多账号

- 只有 1 个账号时界面和单账号一样；2 个以上时右上角出现"账号"切换，总览、战绩、传奇筛选、待确认数都只算选中的账号
- 每次打开窗口默认看最近玩过的账号（在小号上打完、打开 Evo 就是小号）；切换后在这个窗口里一直有效
- "全部账号"时段位卡片和 RP 走势图不显示（几个账号混在一起没有意义），提示选一个账号；导出 CSV 总是导出全部（有 player_name 列）
- 认出新名字时在窗口里弹窗问"是不是同一个人"；选错了在设置页"账号"一栏改（把名字并到别的账号或拆成单独一个）

## 分享战绩（2026-10-21）

- 用户决定：三种卡片都做；队友只显示传奇和这一局的数据，不写名字和 ID；自己的游戏名默认显示，分享前能勾掉。不做"分享链接"（要上传到服务器，违反原则 2）
- 入口：战绩页点开一局，"详情与修改"左边的"分享这局"（待确认的局没有：数据还没确认）；总览页段位卡片右上角"分享"（"今日战绩"和"近 30 局概况 / 全部概况"，范围跟着总览页的按钮；今天没打时"今日战绩"不能选；"全部账号"时没有）
- 对话框（`panel/templates/_share.html`）：预览、"在图上显示我的游戏名"（没认出玩家名时不显示这一项）、有待确认的局时提醒"确认后图上的数字更准"、"复制图片"（写进剪贴板，到微信、QQ 里 Ctrl+V）、"保存图片…"（Evo 窗口里弹 Windows 的"另存为"，默认"图片"文件夹，`app_window.save_image`，只收 PNG；用浏览器打开的面板直接下载）
- 卡片（`panel/templates/share/*.svg`，数据在 `panel_app.py` 的"分享战绩"）：SVG 里放一段网页排版（foreignObject），字体、传奇头像、段位图标、Evo 图标都嵌成 data: 网址；页面把它画成 2 倍大小的 PNG（单局、今日 1440×810，概况 1440×1080）。固定用黑夜主题的颜色，不跟随面板主题；右下角"EVO evotracker.cn"
  - 坑：SVG 要用 data: 网址载入再画到 canvas 上；用 blob: 网址载入的话（里面有 foreignObject），浏览器不让导出
  - 坑：写剪贴板要窗口在前台（自动化测试时窗口在后台会报"Document is not focused"）；ClipboardItem 直接交一个还没完成的 Promise，免得生成慢了超过"刚点过按钮"的时限
- 单局：名次（冠军写"冠军"，按名次上色，和徽章一样）、传奇、模式 · 地图 · 日期时间、击杀 / 助攻 / 击倒 / 伤害 / 生存、RP（只有排位局）、打完这局的段位、两名队友的传奇和数据
- 今日：从早上 5 点算起；今日 RP、现在的段位、局数 / 最好名次 / 总击杀 / 总伤害 / 场均伤害、每局名次（最多 16 个，更早的写"前面还有 N 局"）
- 概况：段位、RP 合计、走势图（和总览页同一个 `rp_chart`）、6 个统计数字、传奇表现（最多 3 个 + 其他，两列）。以后能按赛季看了，改成按赛季（见 todo.md）
- 时间写日期（"10月21日 21:30"，不是今年的加年份），不写"今天""昨天"：图片发出去以后过几天再看就不对了
- 读不到的项写"—"；总击杀、总伤害只加读到的局

## 通知

- **不能做成自定义的置顶窗口盖在游戏画面上**（等于游戏内浮层，违反原则 1；独占全屏时还可能把游戏切到后台）。只能用 Windows 系统通知（外观由系统决定），或者只在没玩游戏时弹出自定义卡片
