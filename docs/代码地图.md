# 代码地图

每个文件是干什么的，一行一个，按分工分组（模型、引擎、页面、底座……见 CLAUDE.md"用词和分工"）。找某个功能的代码在哪时先看这里。

这个文件是 `python tools/code_map.py` 生成的，**不要手改**：每行取自那个文件开头的说明（第一句），说明写得不好就改文件开头。
加、删、改名文件，或者改了文件开头说明的第一句以后，重新运行一次；`python tests/run_all.py` 会检查它是不是最新的。

## 模型

### 记录的主循环、截屏、画面比例和语言

- [live_collect.py](../code/live_collect.py)：实战采集（模型的主循环）：打游戏时在后台运行，按画面识别、记录每一局
- [game_detect.py](../code/game_detect.py)：检测 Apex 有没有在运行：看进程列表里有没有游戏的进程名
- [capture.py](../code/capture.py)：截屏对象：截主显示器，每张是 BGR 的 numpy 数组
- [layout.py](../code/layout.py)：游戏界面在不同宽高比下摆在哪：把配置里的坐标（1920×1080 基准）换算成截图上的像素
- [game_aspect.py](../code/game_aspect.py)：游戏画面的宽高比（16:9、16:10、4:3）：Evo 按它换算界面在截图上的位置（见 layout.py）
- [game_lang.py](../code/game_lang.py)：游戏语言：Evo 认得出哪几种语言的游戏画面，每种语言的识别规则和参照图在哪

### 认出画面，读结算画面和大厅

- [screens.py](../code/screens.py)：判断当前是哪个画面：总结页、经验值页、开局画面、大厅、淘汰画面、冠军横幅、返回大厅按钮（规则在 config/screens.json），都不是返回 None
- [summary_page.py](../code/summary_page.py)：识别赛后总结页：从截图里读出名次、小队总击杀、击杀/助攻/击倒、伤害、生存时间、急救、重生
- [teammates.py](../code/teammates.py)：读总结页上两名队友的数据：名字、ID、击杀/助攻/击倒、伤害、生存时间、急救、重生
- [xp_page.py](../code/xp_page.py)：识别经验值页（RP 明细）：本局 RP 变化、名次、计分的击杀/助攻次数、本局结束后的段位和段内进度
- [eliminated.py](../code/eliminated.py)：识别淘汰画面：小队被淘汰时屏幕中间弹出的"全军覆没 / 排名第 X"，读出名次
- [match_start.py](../code/match_start.py)：识别开局画面：本局的模式和地图
- [lobby.py](../code/lobby.py)：大厅：读自己的玩家名、段位和段内分数（规则在 config/lobby.json），换算成总分
- [player_name.py](../code/player_name.py)：读自己的玩家名（游戏里显示的名字），用来区分账号

### 对局中

- [in_match.py](../code/in_match.py)：对局中（开局画面之后、结算画面之前）：认自己和队友，记下自己的状态，连续保存右上角，一局结束时交给 PostMatch
- [hud.py](../code/hud.py)：对局中的界面（HUD）：左下角自己和两名队友、右上角的数据（规则在 config/hud.json）
- [legends.py](../code/legends.py)：认出自己用的传奇：对局中左下角自己的头像（规则和传奇名称表在 config/legends.json）
- [weapons.py](../code/weapons.py)：对局中右下角手上那把武器（规则在 config/weapons.json，参照图在 config/templates/weapons/）：数据页"最常用武器"用

### 合并、校准、段位、赛季、留截图

- [post_match.py](../code/post_match.py)：一局结束后，把各个来源的数据归到同一局里，按优先级定下每一项（规则见 docs/对局全流程图.md"数据来源和优先级"）
- [calibration.py](../code/calibration.py)：大厅校准：用前后两次大厅读到的总分，核对中间各局的 RP
- [ranks.py](../code/ranks.py)：排位段位（规则在 config/ranks.json）：段位名、哪些段位分段、把"段位 + 段 + 段内进度"换算成一条连续的分数线
- [seasons.py](../code/seasons.py)：赛季（规则在 config/seasons.json）：每个赛季从什么时候开始，每局、每次大厅读数归到哪个赛季
- [screenshots.py](../code/screenshots.py)：记录时存下的截图留不留（原则 2"本地优先"：识别完就删，只留总结页截图和"待确认"的局要用的截图）

### 游戏里的数据页（录入历史赛季数据）

- [season_stats.py](../code/season_stats.py)：游戏里的数据页：认出这一页，读右边一栏（下拉菜单选中的那个赛季的合计）和中间一栏（大逃杀的生涯合计）
- [season_rules.py](../code/season_rules.py)：历史赛季数据的 15 个数：叫什么、游戏里的约数（"1.03K"）怎么读、互相怎么核对、页面上怎么算比例
- [season_import.py](../code/season_import.py)：录入历史赛季数据的"录入模式"：设置页点按钮 → 接下来 MINUTES 分钟里，记录程序认出游戏里的数据页就读（见 live_collect.SeasonWatcher……

### 规则（config/）

- [eliminated.json](../config/eliminated.json)：淘汰画面（小队被淘汰时屏幕中间的'全军覆没 / 排名第 X'）的识别规则，见 eliminated.py；怎么认出这个画面见 screens.json
- [hud.json](../config/hud.json)：对局中的界面（HUD）：左下角自己和队友、右上角的数据（见 hud.py、in_match.py）
- [legends.json](../config/legends.json)：认出自己用的传奇（见 legends.py）：对局中左下角自己的头像
- [lobby.json](../config/lobby.json)：大厅：读自己的玩家名和段位、段内分数（见 lobby.py；怎么认出大厅见 screens.json）
- [match_start.json](../config/match_start.json)：开局画面（左上角横幅'排位赛 - 空降地点'或'排位赛'，看段位：固定跳点制 / 跳伞制；下一行是地图名）的识别规则
- [player_name.json](../config/player_name.json)：读自己的玩家名（游戏里显示的名字），用来区分账号（见 player_name.py）
- [ranks.json](../config/ranks.json)：排位段位：每段的起点（排位点数）、入场费
- [rotation.json](../config/rotation.json)：总览页的地图轮换：统计服务器 GET /v1/maps 给的英文名 → 简体中文名
- [screens.json](../config/screens.json)：怎么认出各个画面（见 screens.py）：总结页、经验值页、开局画面、大厅、淘汰画面、冠军横幅
- [season_stats.json](../config/season_stats.json)：游戏里的数据页（顶部"数据 | 账户进度"两个标签、中间写着玩家名的那一页；见 season_stats.py）：中间一栏是大逃杀的生涯合计，右边一栏用下拉菜单选赛季
- [seasons.json](../config/seasons.json)：每个赛季从什么时候开始
- [summary.json](../config/summary.json)：赛后总结页的识别规则（怎么认出总结页见 screens.json）
- [tester.json](../config/tester.json)：测试工具（code/evo_tester.py）的测试项目，窗口里按这个顺序列出来，测试员选一个
- [weapons.json](../config/weapons.json)：对局中右下角手上那把武器（见 weapons.py）：最常用武器用
- [xp.json](../config/xp.json)：经验值页（RP 明细）的识别规则
- [en.json](../config/lang/en.json)：英文游戏画面的识别规则：只写和简体（config/ 里的各个文件）不一样的地方，读规则时叠上去（见 code/game_lang.py）
- [zh-TW.json](../config/lang/zh-TW.json)：繁体中文游戏画面的识别规则：只写和简体（config/ 里的各个文件）不一样的地方，读规则时叠上去（见 code/game_lang.py）
- [config/templates/](../config/templates/)：参照图（外观检查用）：按画面放；legends/ 传奇头像、weapons/ 武器、hud/ 对局中，en/、zh-TW/ 是英文、繁体游戏和简体不一样的那些

## 引擎

## 底座

- [evo_app.py](../code/evo_app.py)：Evo 主程序：任务栏托盘图标 + 后台自动记录 + 按需打开的面板
- [paths.py](../code/paths.py)：程序文件和用户数据放在哪里
- [source_run.py](../code/source_run.py)：用源码运行 evo_app.py 时，数据放哪里
- [storage.py](../code/storage.py)：本地数据库：把每局数据存进 SQLite（Python 自带，不用安装）
- [app_settings.py](../code/app_settings.py)：Evo 自己的小设置（如"关窗口的提示是否已经显示过"），存在数据文件夹的 settings.json 里
- [data_move.py](../code/data_move.py)：数据文件夹搬家：设置页"更改位置"，和老玩家从 C 盘自动搬到程序旁边（paths.py 第 3 条）
- [autostart.py](../code/autostart.py)：开机自动启动：Windows 开机启动项（注册表 HKCU\...\Run 里的一条"Evo Tracker"），开机时运行 "Evo.exe" --background……
- [process_info.py](../code/process_info.py)：本程序（进程）的内存占用、优先级和省电限速，用 Windows 自带的功能（ctypes），不需要安装别的包
- [icons.py](../code/icons.py)：Evo 的图标：托盘、程序文件（exe）、窗口标题栏和浏览器标签页都从这里取，保证是同一个
- [sounds.py](../code/sounds.py)：对局结束的提示音：一局里最多响三声，每一声每局最多一次（什么时候响见 live_collect.SoundCues）
- [webview2.py](../code/webview2.py)：Evo 窗口要用微软的 WebView2 组件（Edge 用的同一个内核）
- [update_check.py](../code/update_check.py)：检查 Evo 有没有新版本
- [update_patch.py](../code/update_patch.py)：补丁包：一键更新只下载和玩家现在的版本相比变了的文件，以后每次发布都这样
- [updater.py](../code/updater.py)：一键更新：在 Evo 里下载新版本、安装、自动重新打开
- [telemetry.py](../code/telemetry.py)：匿名统计：用户同意了，才把对局数据发给开发者，用来统计有多少人在用、大家用哪些传奇，以及改进识别
- [notice_check.py](../code/notice_check.py)：开发者公告：下载 notice.json 这个公开的小文件，有公告就在 Evo 窗口顶部显示，重要的再用托盘通知提醒一次
- [server/](../server/)：匿名统计的服务器（Cloudflare Worker + D1）：worker.js 收数据、给汇总，schema.sql 建表，wrangler.toml 部署配置
