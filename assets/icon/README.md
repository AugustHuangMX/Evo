# Evo 图标

深色圆角方块上一个由横杠组成的 "E"：一根竖笔，三条右端斜切的横杠，最上面一条是蓝色（2026-10-22 用户的设计稿）。

- `evo.svg`：矢量原稿（1024 的网格）
- `evo.png`：1024 像素，圆角外面透明。托盘、exe、窗口标题栏、面板左上角、浏览器标签页、分享图片都从它来（`code/icons.py`），打包时转换成 Windows 用的多尺寸 `.ico`（16、24、32、48、64、128、256 像素）

这两个文件都由 `python tools/make_icon.py` 生成（同时生成官网的 favicon 和首页大图），不要手动改：要改形状或颜色就改那个脚本里的数字，再运行一次。

## 以后重新设计时的要求

- **缩到 16 × 16 也要认得出**：托盘图标就这么大，形状要简单、线条粗、细节少；在深色和浅色任务栏上都要看得清
- **原创**：不使用 Apex Legends 的标志、EA 的美术素材或游戏里进化护甲的原画（商标和版权）
- 可选：一个"正在记录"的版本（如右下角加个小红点，`evo-recording.png`）。不提供的话，程序会自动在图标上叠一个小红点
