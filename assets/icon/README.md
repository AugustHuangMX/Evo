# Evo 图标

把图标源文件放在这个文件夹里，打包时会转换成 Windows 用的多尺寸 `.ico`（16、24、32、48、64、128、256 像素）。

## 要求

- **正方形、背景透明**：源文件给 1024 × 1024 的 PNG（`evo.png`），有 SVG（`evo.svg`）更好
- **缩到 16 × 16 也要认得出**：托盘图标就这么大，形状要简单、线条粗、细节少；在深色和浅色任务栏上都要看得清
- **原创**：不使用 Apex Legends 的标志、EA 的美术素材或游戏里进化护甲的原画（商标和版权）。面板左上角的盾牌可以作为起点
- 可选：一个"正在记录"的版本（如右下角加个小红点，`evo-recording.png`）。不提供的话，程序会自动在图标上叠一个小红点

在图标做好之前，打包用面板左上角的盾牌临时代替。
