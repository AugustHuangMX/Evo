# 新版本宣传图：做图流程

给新版本的新功能做配图（QQ 群公告、官网更新日志用）。**每次做图都照这里做**，风格固定、能复现（2026-10-21 开发者决定）。

- 不要自己改风格。想改先问开发者；改了以后 `tools/feature_cards.py` 和这份文档一起改
- 图都由脚本生成，不手动 P 图；要调整就改 `release/宣传图.json` 再运行

## 一条命令

```
python tools/feature_cards.py
```

读 `release/宣传图.json`，输出到 `release/<版本号>截图/`（如 `release/0.3.5截图/01-传奇头像.png`），同名的图会被替换。终端会打印每张图放大的区域。排查问题时加 `--keep`，留下临时文件夹（原图、合成用的网页）。

脚本自己做完全部步骤：在临时文件夹里生成演示战绩 → 在本进程里打开面板（不碰正式数据，用完删掉）→ Edge 无界面模式截 Evo 窗口 → 量出要放大的元素在哪里 → 合成。要求：Windows 上装了 Edge（Windows 自带）。

## 步骤

1. **挑功能**：从 `release/更新内容.txt` 的"新增："里挑在 Evo 窗口里看得到的功能，先问开发者做哪几张。"修复："一般不做图（界面上看不出变化）
2. **改 `release/宣传图.json`**：每张图一项，字段见下面。换成这一版的内容（和 `更新内容.txt` 一样，每个版本改一次）
3. **运行** `python tools/feature_cards.py`
4. **逐张打开看**，按下面的检查清单核对
5. **给开发者看**，同时说明图里哪些是演示数据、示例路径；要改就回到第 2 步

## 风格（固定）

| 部分 | 规定 |
|---|---|
| 尺寸 | 1920×1080 PNG |
| 配色 | 深色背景（面板的黑夜主题），强调色 `#FF5A5A`（面板的红色） |
| 左上角 | 小标签"EVO 版本号 新功能" + 大标题。`宣传图.json` 的 `label` 可以改"新功能"这几个字：0.4.0 起写成空的，只有"EVO 0.4.0"（2026-10-25 开发者定的：新功能和主打的特色功能放在一起介绍） |
| 标题 | 只写功能名，越短越好（最好不超过 10 个字），不写句子。数字（如 16:10）自动用面板的数字字体 |
| 标题下面 | **不加说明文字**（2026-10-21 开发者决定） |
| 截图 | Evo 窗口（1280×800，带 Evo 标题栏），要看的地方用红框标出，其余压暗 |
| 另两种排版（0.4.0 起，开发者 2026-10-25 定的） | **只放截图**（`"layout": "full"`）：整页、不放大、不压暗，窗口在标题下面横向居中，用在宽表格（局部放大反而看不清）；**几张并排**（`gallery`）：几张图一样高排成一排，每张下面一个小标签，用在分享卡片这种要一起看的 |
| 底部小字（可选） | `note`：画布最下面一行灰色小字，比如"数据基于所有 Evo 玩家" |
| 放大框 | 每张图只有一个；红边，两条虚线连到红框；上面一个小标签写在哪一页（如"战绩页""设置 › 识别"） |
| 可选 | 放大框右边的小标签（`tags`，如"自己""队友"，不超过 4 个字）；右上角的画面比例示意（`aspect_boxes`，只在功能和画面比例有关时用） |
| 文件名 | `两位序号-功能名.png`，序号按 `宣传图.json` 里的顺序 |

排版是自动的：窗口截图在左下（默认缩到 0.6）；放大框放得下就在窗口右边，放不下就靠画布右边、压住窗口一点；放大框和红框上下居中对齐。放大倍数自动定：最多 2.5 倍，框最宽 600、最高 300（画布按 1280×720 算，输出时再放大 1.5 倍）。

## 演示数据（不用真实数据）

- 战绩是 `tools/demo_data.py` 的随机数（随机种子固定，每次一样；"昨天 23:45"这种时间跟着运行时间变）。数据库叫 `evo.db`，所以页面顶部不显示"演示数据"标签；"待确认"全部去掉
- 随机名次几乎没有第 1 名，大约每 9 局改一局成冠军（RP 按演示数据同样的算法重算，段位前后对得上）
- 队友从三个编的人里每局挑两个（`MATE_POOL`）：名次 1–5 的局多半有夜航灯塔，数据页"常一起玩的队友"里看得出谁是上分好搭子
- 武器（0.4.0 起记录）：每局 3–7 段，按 `WEAPONS` 的权重挑
- 全体玩家：设置里开了匿名统计（这一页才能看），汇总是编的（`write_everyone`，格式和统计服务器一样），存成刚下载过的样子；统计服务器地址指到本机没人听的端口，不联网
- 自己的游戏名和队友名字都是编的（`EvoPlayer`；`夜航灯塔`、`SilverFox_77`、`咕咕鸽`）。**不能出现真实玩家的名字和 ID**（原则 7），也不用游戏截图（里面有别的玩家的名字）
- 设置页的数据文件夹显示成 `E:\Evo Tracker Data`，屏幕分辨率写 `2560 × 1440`，不会截到临时文件夹和 Windows 用户名
- 假的 Apex 视频设置（全屏 2560×1600），所以"自动检测结果"是 16:10，不读这台电脑上 Apex 的设置
- 设置页的"开机自动启动"总是显示"已开启"（用源码运行时开关本来是灰的；也不读这台电脑真实的启动项）
- 这些都写在 `tools/feature_cards.py` 开头的常量里

## `宣传图.json` 怎么写

```json
{
  "cards": [
    {
      "file": "传奇头像",
      "title": "传奇头像",
      "page": "/matches?open={latest}",
      "zoom_on": ["tr.row.open .legend-label", "tr.mate-row .legend-label"],
      "pad": 12,
      "caption": "战绩页",
      "tags": [{"on": "tr.row.open .legend-label", "text": "自己"}, {"on": "tr.mate-row .legend-label", "text": "队友"}]
    }
  ]
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `file` | 是 | 文件名里的功能名（前面自动加序号） |
| `title` | 是 | 大标题 |
| `page` | 是 | 截面板的哪一页（地址，见下面"页面状态"） |
| `zoom_on` | 是 | 要放大的元素：CSS 选择器，一个或一组；一组时合成一块。选择器从 `panel/templates/` 里找 class、id |
| `caption` | 是 | 放大框上面的小标签：在哪一页 |
| `pad` | 否 | 放大区域四周留多少（窗口像素）：一个数，或 `[左右, 上下]`，默认 `[12, 10]`。框里带进了相邻内容的半截字就把上下调小；字贴边就把左右调大 |
| `tags` | 否 | 放大框右边的小标签：`on` 是选择器，匹配到几个元素就在那几行各放一个 |
| `window` | 否 | 窗口截图缩放，默认 0.6。放大框压住窗口里的内容太多、显得乱时改成 0.5 |
| `zoom` | 否 | 放大倍数，一般不用写（自动） |
| `aspect_boxes` | 否 | 右上角的比例示意，如 `[["16:9", false], ["16:10", true]]`，`true` 的标红（新支持的） |
| `layout` | 否 | 写 `"full"`：只放截图，不放大（不用写 `zoom_on`、`caption`；`tags` 还能用，放在窗口右边对准那一行） |
| `gallery` | 否 | 几张并排：`[{"page": 地址, "on": 选择器, "label": 下面的小标签}, …]`，每张从各自的页面里裁出 `on` 那一块（不用写 `page`、`zoom_on`） |
| `note` | 否 | 画布底部的小字 |
| `version`（最外层） | 否 | 图上写的版本号，不写就用程序的版本号（`code/storage.py` 的 `APP_VERSION`） |
| `label`（最外层） | 否 | 左上角小标签版本号后面的字，默认"新功能"；写 `""` 就只有版本号 |

## 页面状态

| 写法 | 效果 |
|---|---|
| `{latest}` | 最新一局的编号。`/matches?open={latest}` 展开最新一局，显示两名队友 |
| `_shot=move` | 设置页"更改数据位置"展开，显示"能搬"的检查结果（搬到 `D:\Games`） |
| `_shot=share` | 打开分享对话框：总览页 `/?_shot=share` 是"今日战绩"（0.3.6 用的这个，开发者选的）；战绩页要同时写 `open={latest}`：`/matches?open={latest}&_shot=share` |
| `_shot=share2` | 分享对话框切到第二种卡片：总览页 `/?_shot=share2` 是"近 30 局概况" |
| `_shot=lang` | 设置页"游戏语言"的下拉框展开成列表、选中 English（截图打不开下拉框）：`/settings?_shot=lang#h-rec` |
| `#h-data` 等 | 滚到页面里这个 id 的位置（标题不会藏到 Evo 标题栏下面） |

新功能要别的状态（弹窗、检查结果、提示条……）时：在 `tools/feature_cards.py` 的 `serve_panel` 里加一个 `_shot=…`，只在这个工具里改，不改面板代码；加了写进这张表。

## 检查清单

- [ ] 放大框里的字完整，没被切掉，也没带进相邻内容的半截字
- [ ] 红框和放大框里是同一块
- [ ] `tags` 的小标签对准对应的那一行
- [ ] 没有真实玩家的名字、ID，没有 Windows 用户名、临时文件夹路径
- [ ] 标题下面没有说明文字；版本号对
- [ ] 放大框没有挡住红框，也没有超出画布

## 已知的坑（脚本里已经处理）

- Edge 读网页内容（`--dump-dom`）时页面比截图小一圈（扣掉了窗口边框），量出的位置会偏：脚本先量出实际大小，不是 1280×800 就把窗口调大再量，必须和截图一样大
- 面板打开时有动画（整页往上浮 10 像素、队友两行落下、走势图从左往右展开），没播完就量会偏、截到的走势图没有曲线：量位置和截图时都关掉动画（0.4.0 时发现上分趋势那张丢了曲线）
- 面板改了页面结构以后，`宣传图.json` 里的选择器可能找不到元素：脚本会报"页面上找不到 …"，去 `panel/templates/` 里找新的写法

## 放到官网时

图放到官网（`site/`）时，按原则 8 用 ui-ux-pro-max。
